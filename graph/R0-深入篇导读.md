# 深入篇导读:手写一个图运行时(路线 B)

> 主线造的是家族 A(循环 + Harness,mini Claude Code)。本篇造家族 B 的核:一个 **LangGraph 式的图运行时**——把 Agent 的状态与控制流从进程里取出来,建模成"节点 + 边 + 可序列化状态",由 Pregel/BSP 引擎驱动,获得确定性并发、检查点持久化、真中断与时间旅行;再在它之上重建 `create_agent` 与中间件系统(对应 LangChain 1.x)。读完你能看懂 LangGraph 源码,也能自己写一个。

## 进入本篇之前

- **前置**:主线第 0、1 章(消息/模型/工具/循环这四个模块,本篇直接复用其概念)。强烈建议也读过第 10 章(桥)——它讲清了"哪些问题 harness 已经解决、哪些真正需要图",带着这张账单来读,每个抽象的动机都会清晰一倍。
- **代码**:本篇使用 `code/tinygraph`(运行时)与 `code/tinyagent`(Agent 层),与主线的 `tinycore`/`tinyharness` 是**平行**的两套实现;消息/模型/工具三件套两边概念同构(tinycore 多了 usage 等生产字段)。
- **编号**:各章保留原两层教程的章号体例——R1 即原第 2 章(小节号 2.x),R2 即原第 3 章(小节号 3.x),依此类推。

## 两条路线的对读提示

本篇与主线处处照应,遇到下列主题时值得翻回去对比——**同一个问题,两种形式化程度的答案**:

| 问题 | 主线(harness)的答案 | 本篇(图)的答案 |
|---|---|---|
| 持久化 | 事件日志重放(第 5 章) | 检查点快照链(R3) |
| 并行确定性 | 执行器按请求顺序收集(第 2 章) | Channel + Reducer 合并语义(R2) |
| 等待人类 | 审批回调阻塞 / 会话挂起(第 6 章) | `interrupt()` = 存盘退出再重跑(R4) |
| 回到历史 | fork 日志前缀(第 5 章) | 检查点时间旅行 + 状态编辑(R3) |
| 扩展点 | 钩子(使用者,时机点)(第 7 章) | 中间件(开发者,洋葱包裹)(R6) |
| 多智能体 | task 工具 + 上下文隔离(第 8 章) | 子图即节点 + 边拓扑(R7) |
